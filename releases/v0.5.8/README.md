# Crayon CLI v0.5.8 files

This directory contains the v0.5.8 Python CLI project and the scoped npm launcher package.

- [Python project](python-project/README.md)
- [npm package](npm-package/README.md)
- [v0.5.8 release notes](python-project/RELEASE_NOTES_v0.5.8.md)

The Python CLI is a separate scaffold and migration experiment. Its release notes state that full feature parity with the v0.5.7 TypeScript CLI and inference backend has not been verified. It should be treated as a standalone package snapshot, not as a feature complete replacement.

Both package manifests specify Apache-2.0 and include a LICENSE file. This commit uploads source files to the repository; it does not create a GitHub release or tag.
